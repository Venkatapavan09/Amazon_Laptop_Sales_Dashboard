# 💻 Amazon Laptop Sales Dashboard

## 📌 Project Overview

This project is an interactive **Power BI Dashboard** built to analyze Amazon laptop sales data. It provides insights into sales performance, product availability, pricing, customer ratings, and brand-wise analysis.

---

## 🛠️ Tools Used

- Power BI
- Microsoft Excel
- Power Query
- DAX

---

## 📊 Dashboard Highlights

- Sales Overview
- Brand Analysis
- Product Analysis
- Stock Analysis
- RAM Analysis
- Hard Disk Analysis
- Price Analysis
